# Contributing

Created by School of AI and School of QC.

Open an issue before a large change. Use a focused branch, add tests for changed behavior, run
`ruff check .`, `ruff format --check .`, and `pytest`, then describe data, metric, or API changes
in the pull request. Preserve leakage controls and clearly distinguish simulator results from
hardware results. By contributing, you agree that your work is licensed under the MIT License.
